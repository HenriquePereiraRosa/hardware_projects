Normalize the 12 V and 5 V rail names

Final naming

J1 raw 12V_IN → F1 → D6 → 12V → A2 → 5V → JP1 → 5V_MCU → ESP32

The widely distributed protected input is 12V. The normal regulator output is simply 5V. Only the isolated ESP32 side of jumper JP1 remains 5V_MCU. The ESP32 DevKit creates 3V3.

Why two 5 V names remain

5V and 5V_MCU are separated by JP1 so the ESP32 can be disconnected during USB servicing. They must not be merged across the jumper.

Run

  1. File → Save All.
  2. File → Run Script → Browse → From File.
  3. Open PowerRailFix.PrjScr.
  4. Run FixPowerRailNames.
  5. Validate PCB Project, then use Design → Update PCB Document to transfer the renamed net.

The script backs up the five affected native sheets and checks the expected rail counts before editing. It does not touch the PCB or capacitor orientation.
