Component refresh sources

These native SchLib files are unchanged copies from the user's installed Celestial Altium Library by Mark Harris. See the original README and licence. No database credentials are copied.

The native refresh imports artwork into wiring-preserving, part-specific variants. Added lead strokes, local model links and IEC resistor graphics are project adaptations, not original manufacturer CAD. Exact input hashes and mappings are recorded in the manifest.

The non-IPC polarized-capacitor symbol is selected: its positive plate is pin 1. The unused IPC variant has the opposite numbering and is archived under deprecated; do not substitute it without revisiting the pin mapping.
