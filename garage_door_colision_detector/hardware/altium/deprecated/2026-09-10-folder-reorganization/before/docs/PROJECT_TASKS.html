○

F04 · Prove unsafe behaviour on hardware

Test blocked beams, disconnected receiver cables, lost emitter/receiver power, MCU restart and total power loss. Missing signal and blockage may share the same unsafe indication. A static NPN output cannot diagnose every stuck-ON fault or signal-to-ground short. A dark/unpowered indicator must never be treated as permission to close.

M05 · Commission and record real results

Measure transition spread/hysteresis at 2.4 m, alignment drift, car reflections, adjacent-beam interference and actual vehicle coverage. Reject any observed false CLEAR; investigate transition spread beyond ±3 mm. Agree a complete door-motion/installation tolerance budget. Sparse beams do not automatically establish an entire safe plane.

How to read this checklist

Completed

The named artifact exists or the explicitly stated check passed. For example, “STEP embedded” does not mean “mechanical alignment verified.”

Partial / To do / Optional

Partial has usable work but missing verification or implementation. To do remains required. Optional does not block the agreed advisory version. No completion percentage is shown because the tasks differ greatly in effort and risk.

Evidence reviewed: native project document list, hierarchy exports/checker, component-library update records, firmware sources/tests and the documentation/mechanical inventory. Latest revision includes the Celestial schematic footprint-link and PCB package update; see its separate audit and limitations.

This is a dated, read-only status snapshot. Filters change only visibility; they do not mark engineering tasks complete. Update this file after each verified iteration.
