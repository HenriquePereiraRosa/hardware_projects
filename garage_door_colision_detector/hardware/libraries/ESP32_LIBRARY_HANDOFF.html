What the finished Altium component needs

  • .SchLib: editable electrical symbol with actual pins and manufacturer parameters.
  • .PcbLib: matching 38-pin footprint, linked to the symbol.
  • .STEP/.STP: complete development-board model attached to that footprint, including socket height where applicable.

A schematic symbol is a logical representation; 3D belongs to its linked PCB footprint. An ESP32 symbol normally uses a rectangular body with real named pins. Resistors, diodes and transistors should use their conventional electrical symbols.

If supplied as native libraries, open them in Altium with File → Open; install through the Components panel's file-based library preferences as appropriate for the installed version. Exact import steps depend on the downloaded archive format. Do not rename arbitrary files to .SchLib or .PcbLib.
