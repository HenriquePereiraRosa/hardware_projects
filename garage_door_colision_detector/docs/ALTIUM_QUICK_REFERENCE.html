Where to get real components with 3D models

  1. Best: download the STEP model and drawing from the exact component manufacturer's product page. The manufacturer datasheet remains the authority for pin numbers and dimensions.
  2. Inside Altium: open View → Panels → Manufacturer Part Search. Search the exact manufacturer part number and prefer entries marked ECAD Ready, with symbol, footprint, and 3D model. Altium's own documentation distinguishes these qualified models from generic/unqualified entries.
  3. Good secondary sources: SnapMagic (formerly SnapEDA), SamacSys Component Search Engine, and Ultra Librarian. Always compare pad dimensions, pin 1, body size, and connector orientation with the current datasheet.
  4. Modules such as ESP32 DevKit and buck boards: lock the exact board revision first. Module sellers often change PCB dimensions and pin labeling without changing the listing title, so a downloaded model is not trustworthy until checked against the board in hand.
Current project status: the PCB now contains 38 simple extruded clearance bodies generated from its footprint bounds. They help with basic height/enclosure work, but they are not real-looking manufacturer STEP models. The present generic symbols/footprints must be replaced with exact orderable parts before fabrication.

Safe project workflow

  1. Edit the schematic first.
  2. Run Project → Validate PCB Project and resolve unintended errors.
  3. Run Design → Update PCB Document and inspect every ECO.
  4. Place connectors and mechanical constraints first, then protection, sensor channels, controller, and UI.
  5. Route power and ground first, then beam inputs, then indicators.
  6. Run DRC and inspect 3D before generating manufacturing outputs.

Project-specific warnings

  • This advisory detector must not replace the garage-door manufacturer's safety system.
  • CLEAR requires active current from every enabled sensor. Open wiring, missing sensor power, and ESP32 startup remain unsafe.
  • Do not order the current PCB until the actual DevKit, terminals, DC/DC module, sensors, footprints, and connector pin numbering are physically verified.
  • The PCB is not the optical datum; alignment belongs to the adjustable wall brackets.
