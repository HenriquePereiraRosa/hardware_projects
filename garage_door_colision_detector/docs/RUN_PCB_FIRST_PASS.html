Run PCB First Pass in Altium

Prepared 10 September 2026. You run this inside your existing Altium installation. No ESP32, cable, Wi-Fi or PCB hardware connection is needed.

The missing connection mentioned in chat is the assistant's desktop-control integration. This local script avoids needing that integration.

What this first pass does

  • Checks that the current hardware_projects project is open and that the documents it reads are saved.
  • Checks the exact ESP32 part and 38 unique pin identifiers.
  • Creates timestamped backup copies of the power schematic and local ESP32 schematic library before modification.
  • Corrects GPIO34 / J2_5 and GPIO35 / J2_6 to Input, both in A1 and in its existing local library symbol. Rerunning leaves already-correct types unchanged.
  • Verifies the ESP32 pin identifiers, locations, orientations and footprint mapping did not change.
  • Exports a fresh schematic and PCB inventory with pin/pad identifiers, PCB nets, component positions and counts of component-owned 3D bodies. This is the evidence needed before the next grouping/model-repair script.

This is a narrow repair plus inventory, not the completed PCB merge. It does not add the transmitter section, move components, replace 3D models, change the macro page, repair capacitors, suppress ERC warnings or execute an ECO. A body count does not prove the correct STEP model is attached. It does not clear every warning in your report.

Execution steps

  1. Open C:\dev\projects\h\hardware_projects\garage_door_colision_detector\GarageBeamSafety.DsnWrk. Close old generator/repair script projects so you cannot run the wrong one.
  2. Choose File > Save All. Save your actual edits; do not discard them. Close any read-only/conflict prompts before continuing.
  3. Choose File > Run Script, then Browse > From File.
  4. Select PCBFirstPass.PrjScr at hardware\altium\scripts\PCBFirstPass\PCBFirstPass.PrjScr.
  5. Expand PCBFirstPass.pas, select RunPCBFirstPass and click OK. Alternatively open the script project and its .pas file, then press F9 and choose the same procedure.
  6. Wait for the completion dialog. It gives the backup/report folder. Do not run another old script.
  7. Right-click GarageBeamSafety.PrjPcb and choose Validate PCB Project (or the equivalent Validate/Compile command shown by your version).
  8. Send back the new compiler messages and the generated report.txt. Do not execute an ECO that proposes unexplained changes.

Output location

Each run creates hardware\altium\History\pcb-first-YYYYMMDD-HHMMSS\ containing report.txt, 01_Power_Control.before.SchDoc and ESP32-DEVKITC-32E.before.SchLib. These files do not exist until the script runs. COMPLETE in the report means this limited pass completed, not that the whole design passed ERC or is ready to fabricate.

If it stops

Send the error text/screenshot and any report. Do not repeatedly retry an unknown failure. In the script editor, use Run > Stop (Ctrl+F3) if needed. The script refuses unexpected parts, duplicate pins or unsaved documents; it does not guess.

Save operations on two files are not one atomic transaction: the library may have saved before a later error. The report records SAVED_LIBRARY and SAVED_SCHEMATIC separately. To roll back, first preserve any later user edits, close the affected documents, then copy the corresponding backup to its original path. Do not save stale open documents over a restored copy. Ask for help if uncertain.
