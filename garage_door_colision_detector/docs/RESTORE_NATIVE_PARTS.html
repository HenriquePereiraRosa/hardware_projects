What this script does

Current version: Revision 7 — fresh replacements plus targeted ID collision repair. The previous run passed 35 components; only the cross-sheet ID pairs D1/D2 and R5/R14 failed. This version scans the registered copies, changes only empty or duplicated IDs, uses Altium's native ID generator and explicit SetState_UniqueId method inside edit notifications, and reads each result back from the sheet. It then independently verifies all 39 components. Unresolved collisions still block saving; checks have not been suppressed.

Altium's new IDs are accepted. It still checks every designator, library symbol, body, pin count and pin position. A successful structural verification has CHECKED=39|PASSED=39|FAILED=0|ISSUES=0, followed by COPIES_SAVED. Manual reconnection and full electrical validation remain separate requirements.

Existing wires are left untouched. No automatic wire bridges are created. Check and reconnect the replacement components manually; displaced pins are listed under MANUAL_CONNECTION, with old/new coordinates under PIN. Oversized symbols are placed anyway and flagged under MANUAL_LAYOUT. Recheck any pins that happen to touch existing wires too.

PCB links must be reconciled later. The report records UID_MAP entries with designator, sheet, old ID and new ID. Do not run a PCB update until schematic-to-PCB component links have been reviewed. The PCB is neither deleted nor edited by this script.
