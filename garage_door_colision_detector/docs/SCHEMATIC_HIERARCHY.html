Where are the detailed schematics?

In Altium's Projects panel, expand Source Documents → 00_Mounting_Overview.SchDoc using the small triangle to its left. Pages 01–05 are nested underneath, not removed. Double-click a child filename to open its detailed schematic.

From Page 0 itself, right-click inside a block and choose Sheet Symbol Actions → Open SubSheet. The POWER / ESP32 block was tested in Altium and opens the existing 01_Power_Control.SchDoc circuit. Do not choose Create Sheet From Sheet Symbol for these existing pages.

The project was saved with all six schematic documents included. This visibility/navigation correction does not replace any detailed circuit or change the PCB. Page 05 retains the installation drawing.

Connecting without long wires

Within one sheet use Place → Net Label on short wire stubs. Identical names join the stubs on that sheet. Keep short, local circuit connections as wires so their function remains obvious.

Between sheets use Place → Port on the child and a matching Sheet Entry on the parent block. Match names exactly. The parent page joins the entries using named tags. A plain label on one child must not be assumed to connect to a label on another child.

Use hierarchical net identifier scope. Altium's Automatic mode selects Hierarchical when the top page contains sheet entries. Do not change to Global to hide a missing port.

Checks and limitations

node hardware/altium/scripts/check_hierarchy.cjs checks saved native export files for five sheet links and 35 matching wired entries/ports. It does not substitute for native ERC or PCB verification.

The existing full-circuit checker currently fails at A1.J2_1 (3V3). The native export reports the pin at x=4800 mil while its existing wire ends at x=4600 mil. Similar ESP32 gaps need review.
