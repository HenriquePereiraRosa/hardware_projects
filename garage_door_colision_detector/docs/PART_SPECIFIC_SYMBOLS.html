Part-specific native symbols

9 September 2026. Targeted schematic/library update; not a PCB release.

PartSpecificComponents.SchLib contains six reusable native components: Phoenix 1729128, 1715734 and 1729144 terminals; Murata OKI-78SR-5/1.5-W36-C converter; Omron E3Z-T61-L 2M and E3Z-T61-D 2M optical heads.

  • Six terminal instances now use screw-contact symbols instead of enclosure rectangles.
  • A2 now uses a DC/DC converter symbol and a native footprint link with 1=VIN, 2=GND, 3=VOUT. Its footprint embeds a matching KiCad community STEP model.
  • Eight optical-head instances retain their functional optical glyphs and cable pins, without blue rectangular frames. These represent complete powered heads, not bare photodiodes.
  • The supplied SnapEDA ESP32 symbol was preserved. Hierarchical sheet blocks and all child sheets remain intact.

Provenance and limits

New schematic symbols are project-authored native Altium library components, not vendor-issued CAD. Creating this library does not certify the entire electronics design. Optical heads are external wired parts with no fictional PCB solder pads.

Omron's manufacturer STEP endpoint returned HTTP 403; no genuine optical-head 3D model is embedded. Phoenix MKDSN 1729128/1729144 footprints currently contain datasheet-based pads, not a finished body outline/courtyard or 3D model. Do not substitute the taller MKDS model. Murata STEP registration still requires visual verification. PCB instances were NOT updated in this iteration.

All existing pin coordinates, wire vertices and net labels on sheets 01–04 compared unchanged with the saved pre-update audits. The five-link/35-entry hierarchy check passes. These checks do not clear the previously reported full-circuit/ERC issues.

Recovery

Pre-change files are in hardware/altium/History/component-symbols-20260909. Files prefixed live- include the open Altium documents saved immediately before modification. Keep these backups. Do not run old full-sheet rebuild scripts over these changes.

Sources: Murata pinout/dimensions; Phoenix 1729144; Phoenix 1729128; downloaded CAD URLs and SHA-256 hashes. KiCad asset license is retained alongside the files.
